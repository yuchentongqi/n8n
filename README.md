这是我发布的第二个，是一个n8n自动化流程生成文章并且发布到微信公众号，WordPress，以及小程序上面。（小程序需要再小程序开发平台里面调用WordPress的api）

需要下载的社区节点有微信和飞书，两个节点：  n8n-nodes-feishu-lite  和  n8n-nodes-wechat-offiaccount 我用的这两的社区节点。

里面的一些隐私部分已经去掉了，所以还需要自己添加一些api密码等要素才能启动，那么接下来我们一步一步来讲

第一个是挑选提示词的部分，这里面的各种池子，可以添加我也举了几个例子。

第二个是生成ai文章，授权的秘密，与url，以及文章里面的prompt都是可以换的，我只写了个大纲，具体想要的要求你们可以自行更换，或者问ai让他自动生成，

第三个是尾注，内容可以自行填写，比如：想看更多精彩内容，上哪哪哪去看等等的。

第四个是摘要推送和报错，你可以拉群里发，也可以让bot单独给你发，我是拉群发的，但是呢你要去飞书开发平台去创建一个bot，具体怎么创建的话可以问问ai，或者稍微查找一些资料就知道了。

第五个是wordpress的 create a post ，这个要去用你自己的WordPress的api

第六个是生成照片，我用的是免费的Pexels网站，你们也可以去用别的网站

第七个是生成照片到素材库，这个需要自己去用自己的微信公众号的api

第八个是发布草稿，这个也需要自己的api，然后你也可以直接发布
